# Mambo Everywhere

Mambo. Proudly everywhere.

A Chrome extension that brings Mambo to your browsing experience.

## Features

- **Interactive Mambo:** Plays Mambo when interacting with supported website elements.

## Installation

Mambo Everywhere is distributed manually rather than through the Chrome Web Store.

1. Download the latest release.
2. Extract the downloaded ZIP file.
3. Open Chrome and navigate to `chrome://extensions`.
4. Enable **Developer mode**.
5. Click **Load unpacked**.
6. Select the extracted extension folder containing `manifest.json`.

## Planned Features

- **Occasional Mambo:** Randomly play Mambo during browsing.
- **Different Mambo Attitudes:** Vary Mambo's playback style.
- **More Interactions:** Expand the range of user interactions that can trigger Mambo.
