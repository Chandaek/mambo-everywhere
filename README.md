# Mambo Everywhere

Mambo. Proudly everywhere.

A Chrome extension that brings Mambo to your browsing experience.

## Features

- **Interactive Mambo:** Plays Mambo when interacting with supported website elements.

## Planned Features

- **Occasional Mambo:** Randomly play Mambo during browsing.
- **Different Mambo Attitudes:** Vary Mambo's playback style.
- **More Interactions:** Expand the range of user interactions that can trigger Mambo.
