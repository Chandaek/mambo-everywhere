# Mambo Everywhere

Mambo. Proudly everywhere.

A Chrome extension that brings Mambo to your browsing experience.

## Features

- **Interactive Mambo:** Plays Mambo when interacting with supported website elements.

## Installation

1. Visit the [Releases](https://github.com/Chandaek/mambo-everywhere/releases) page.
2. Download the latest `mambo-everywhere-*.zip` release asset.
3. Extract the ZIP file.
4. Open Chrome and navigate to `chrome://extensions`.
5. Enable **Developer mode**.
6. Click **Load unpacked** and select the extracted folder containing `manifest.json`.

## Planned Features

- **Occasional Mambo:** Randomly play Mambo during browsing.
- **Different Mambo Attitudes:** Vary Mambo's playback style.
- **More Interactions:** Expand the range of user interactions that can trigger Mambo.
